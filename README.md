# Cosecha Áurea

Frontend empresarial para una tienda demostrativa de vainas de vainilla premium mexicana de Papantla, Veracruz.

## Características

- Catálogo responsivo de cuatro presentaciones.
- Carrito lateral interactivo y ordenamiento por precio.
- Secciones de origen, perfil sensorial, mayoreo y preguntas frecuentes.
- Imágenes optimizadas y metadatos sociales.
- Publicación automática en GitHub Pages.

> Proyecto escolar de demostración. Los precios son ilustrativos y no se procesan pagos.

## Desarrollo local

```bash
npm install
npm run dev
```

## Compilar para GitHub Pages

```bash
npm run build:pages
```

La rama `github-pages` publica automáticamente el contenido mediante GitHub Actions.
